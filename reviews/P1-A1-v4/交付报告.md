```python
def append(self, handler):
    if "priority" not in handler.extras_configs:
        handler.extras_configs["priority"] = 0
    self._handlers.append(handler)
```

按返回顺序依次 `await handler.handler(event)`。⇒ 执行顺序 = priority 降序，最小 priority 最后执行。
