## 一、R1：文本保真的实质缺陷（已修）

**原问题**：`_tidy_deleted()` 里 `re.sub(r"[ \t]+$", "", cleaned, flags=re.M)` 会删除**所有行**的尾随空格，
包括那些根本没发生删除的行。审查举的例子成立：第一行 `"  前言保留空格  "` 的尾随空格也会被吃掉。

**改法**：删掉这条全局 trim，改成逐行处理——

```python
def _tidy_deleted(orig, cleaned):
    if cleaned == orig:
        return orig                      # 没删除 → 一个字不动
    o, c = orig.split("\n"), cleaned.split("\n")
    if len(o) != len(c):
        return cleaned                   # 跨行删除 → 不做行级处理，避免误删
    out = []
    for o_line, c_line in zip(o, c):
        if c_line.strip() == "" and o_line.strip() != "":
            continue                     # 本来有内容、删完只剩空白 → 这行是残留，丢掉
        out.append(c_line)               # 其余逐字保留（含行尾空格）
    return "\n".join(out)
```

**空白规范（本轮明确锁定，请审查方裁定）**：
1. 只删标签及其内部内容；
2. **不修剪行尾空格、不动缩进、不压空行**；
3. 删除后整行只剩空白、且原文该行有内容 → 整行丢弃（这是标记被删走的残留）；
4. 成对结构跨行删除（行数变化）→ 不做行级处理。

> ⚠️ 需要你确认一处：你给的例子
> `"  前言保留空格  \n正文 <invoke name=\"x\">内部</invoke>  \n"` 期望 `"正文 \n"`。
> 按上面第 2 条（不修剪行尾空格），我实现的输出是 `"正文   \n"`（正文后 1 个原有空格 + 2 个尾随空格）。
> 我选择"逐字保留"而不是"顺手 trim"，因为 trim 正是 R1 指出的错误来源。
> 如果你要求"标签位置处的尾随空格也清掉"，请明确规则，我按你的规则改并锁测试。
