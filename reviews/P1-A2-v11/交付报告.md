## 二、四条修复

### 2.1 隔离贯穿整个扫描

v10 只在 `_match_r1()` 的局部循环里把游标移到候选终点；主循环从 `tag_end` 重扫时，
候选内部仍会被 R1/R2/R3 看到。

v11 新增 `_candidate_regions(text, code_regions)`：在 CODE 外扫描所有
「带尖括号双竖线、标记后以 `/` 开头、但没有通过 `_match_new_close()`」的候选，
把从候选起点到候选终点（引号感知的 `>` 之后；无 `>` 到文本末尾）整个区间收集起来。

`_clean_segment()` 里：

```python
isolated = _candidate_regions(t, code)
skip = _merge_regions(regions + isolated)   # regions = CODE ∪ QUOTE
```

`skip` 同时用于：

- 主循环的区间跳过；
- `_match_r1()` 的栈扫描跳过与 COMPLETE 相交判定（R1-f 精神）；
- `_xml_deletions()` 的保护集合。

候选之后的内容不在隔离区间内，继续按原规范处理。

### 2.2 UNCLOSED_SINGLE 后的重扫

因为隔离区间已经并入 `skip`，主循环删除外层起始标签、把游标设到 `tag_end` 之后，
重扫时命中 `skip` 会直接跳到候选终点，不会再看到候选内部的标记。
候选之后的普通正文（例如 `TAIL`、`后缀`）不受影响，继续走 R2/R3。

### 2.3 有区分力的测试

新增 `二十一` 组 12 项：

- `KEEP_ME` 正文在栈内候选、顶层孤立候选、候选属性含 `>` 三种场景下保留；
- 顶层孤立候选内部有完整 `invoke` 起止标签时，`INNER` / `TAIL` 保留（v10 会丢 `INNER`）；
- 候选之后有裸标记、有完整结构时，候选之后的正文保留；
- 外层完整但含候选 → R1-f 跳过外层，候选之后的合法结构仍按规范清理；
- R1-c 只删外层起始标签；MISMATCH 不删正文。

### 2.4 R1-c / MISMATCH / skip_to

- `UNCLOSED_SINGLE` / `CROSS_PARAGRAPH` 只删起始标签（`tag_end`），不扩到正文；
- `MISMATCH` 不删除任何字符，`skip_to` 是引号感知的闭合标签终点；
- `COMPLETE` 与隔离区间相交时整体跳过（R1-f），不删正文。

## 三、配套实现调整

- `_match_r1()` 入口和栈内扫描都改为**先认标签名、再扫属性**。
  标记后不是白名单标签（例如 `<｜｜DSML｜｜ 后缀`）按 NOT_R1 交给 R2/R3，
  不再因为 `_scan_attrs` 的 `MISSING_END` 把整段吞到文本末尾。
- 裸标记（无尖括号）不再进入 R1 栈（`kind == "open_double" and m["angle"]`），
  避免候选之后的裸标记把栈深度撑到 2、误判 NESTED_UNCLOSED。
- 非法候选本身按「不猜、不删」保留原样，可能残留标记；这是有意的取舍，
  不为消除标记而删除候选内部或之后的正文。
