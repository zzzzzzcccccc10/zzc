## 一、R5：CRLF 闭围栏识别（已修）

**问题**：`_code_regions()` 的关闭正则是

```python
close = re.compile(r"(?m)^ {0,3}" + re.escape(ch) + "{%d,}[ \t]*$" % n)
```

Windows 换行（`\r\n`）时行尾是 `\r` 在前，`$` 只能匹配 `\n` 之前的位置且 `[ \t]*` 不含 `\r`，
于是闭围栏匹配不到 → 解析器把闭围栏之后的内容一直保护到文本末尾，**围栏外的控制标记逃过清洗**。

**改法**（一行）：

```python
close = re.compile(r"(?m)^ {0,3}" + re.escape(ch) + "{%d,}[ \t]*\r?$" % n)
```

只允许行尾多一个 `\r`，其余规则不变（独立行、同字符、长度不小于开始、后面只能空白）。
